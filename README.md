Welcome to the world of Roblox scripting! Roblox uses a programming language called Luau, which is a fast, easy-to-learn version of Lua. Scripting is what turns a static 3D world into an interactive game—allowing you to create opening doors, moving platforms, or custom keeping track of player scores.

Here is a quick guide and a few beginner-friendly scripts to get you started in Roblox Studio.

1. Where do you put scripts?
To start coding, you need to open Roblox Studio and look at the Explorer window (usually on the right side).

Right-click on ServerScriptService or a specific Part in your Workspace.

Hover over Insert Object and click Script.

2. Your First Script: Printing a Message
The simplest thing a script can do is send a message to the Output window. This is incredibly useful for testing if your code is working.
